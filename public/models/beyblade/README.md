# Selected Sketchfab models

Original self-contained GLB downloads supplied by the user are bundled at:

- `drake-brave.glb`: https://sketchfab.com/3d-models/beyblade-x-drake-brave-g-4-70-i-fd9a579fcf6348328e580e01cb89bfa4
- `unicorn-delta.glb`: https://sketchfab.com/3d-models/beyblade-x-unicorn-delta-po-3-60-gu-de67e7418fd64ef8ad01172ffdea1487

The loader centres the assembled models, normalizes their XZ diameter to 0.98
arena units and places their lowest point at floor height. Game motion spins the
assembled root; the bundled spin/explode animation clips are not played.
Original GLB data, textures and embedded creator/licence metadata are preserved.
The start button waits for both models to load. Procedural shapes are only
loading placeholders, and a failed model download is reported with a retry hint.
